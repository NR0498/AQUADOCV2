# NLA 2017 raw dataset

The initial dataset is the EPA National Lakes Assessment 2017 report download supplied locally in `NLA 2017 Report Data Files/`. On 2026-10-22, 15 selected files were moved to `data/raw/nla2017/`. Their original names and bytes were preserved, including the original spelling `NLA17_polgons.zip`.

Source catalogue: [EPA National Aquatic Resource Surveys data](https://www.epa.gov/national-aquatic-resource-surveys/data-national-aquatic-resource-surveys).

## Selected files

| Files in `data/raw/nla2017/` | Role |
| --- | --- |
| `nla_2017_water_chemistry_chla-data.csv` and matching `-metadata.txt` | Core: chlorophyll-a laboratory observations, quality flags, analytical dates, units, and detection/reporting limits |
| `nla_2017_site_information-data.csv` and matching `-metadata.txt` | Core: visit and site identifiers, lake context, and coordinate definitions |
| `nla_2017_profile-data.csv` and matching `-metadata.txt` | Core: actual index-site GPS fields, arrival time, water-column depth, scum, and surface conditions |
| `NLA17_polgons.zip` | Spatial support: lake boundaries for shoreline and open-water screening; kept as the original ZIP |
| `nla_2017_secchi-data.csv` and matching `-metadata.txt` | Supporting observations: clarity and index-site depth |
| `nla_2017_phytoplankton_count-data.csv` and matching `-metadata.txt` | Later bloom research: biological observations |
| `nla_2017_phytoplankton_taxa-data.csv` and matching `-metadata.txt` | Taxonomic lookup needed to interpret phytoplankton counts |
| `nla_2017_algal_toxin-data.csv` and matching `-metadata.txt` | Later bloom research: separate toxin observations and analytical metadata |

The remaining 30 downloaded files stay in the original folder. Basin catchments, benthic organisms, zooplankton, atrazine, E. coli, survey population estimates, and other report outputs are not selected for this first chlorophyll workflow. Supporting measurements are not automatically model predictors: deployed inference must only use inputs that will actually be available.

## Inventory findings

- The chemistry CSV contains 22,873 rows across multiple analytes.
- Selecting **exactly `ANALYTE == CHLA`**, after trimming and uppercasing, gives **1,210 records**, 1,210 visit UIDs, and 1,113 distinct site IDs. A substring search for `CHL` would incorrectly include chloride.
- All 1,210 chlorophyll records have raw units `UG/L`, matrix `WATER`, sample type `CHLX`, and sample code `REGULAR`.
- 1,172 chlorophyll rows have a blank `NARS_FLAG`; 38 have `S`. Interpret the flag with authoritative source documentation before deciding eligibility. Blank flags alone do not establish training suitability.
- The site metadata explicitly describes `LAT_DD83`/`LON_DD83` as NAD83 site-selection coordinates, often lake centroids. The profile table supplies `INDEX_LAT_DD`/`INDEX_LON_DD`; inspect those first for the observed sampling location, check datum and join completeness, and record any fallback.
- Chemistry collection dates have no collection-time column. Profile `ARRIVAL_TIME` is arrival time at the index site, not automatically the exact chlorophyll collection timestamp. Preserve date/time precision rather than inventing exact collection times.
- The profile CSV did not decode as UTF-8; it was read successfully as Windows-1252 for inspection. Raw encoding was not changed. Document the explicit decode policy when building the importer.

These are counts of raw observations, not counts of approved satellite/measurement pairs or training-ready examples.

## Integrity and Git handling

The reviewable inventory at [data/manifests/nla2017_raw.json](../../data/manifests/nla2017_raw.json) records every selected file's original path, new path, byte size, SHA-256, role, and CSV inventory where applicable. All 15 hashes were checked again after moving.

The root `.gitignore` excludes both `/NLA 2017 Report Data Files/` and `/data/raw/nla2017/`. The small manifest and this guide remain available for version control. Raw observations must be transferred or re-downloaded separately when setting up another machine.

## Preprocessing status

Source-specific preprocessing is now implemented. Run `python -m aquadoc_core.cli preprocess-nla2017` from the repository root. The first run produced 1,145 provisional candidates and 65 review records, retaining all 1,210 chlorophyll observations and leaving raw files unchanged. Generated files are in the Git-ignored `data/processed/nla2017/` directory.

See [the preprocessing report](nla2017-preprocessing.md) for transformations, quality policies, counts, verification and remaining limitations. Date-only observations require a precision-aware database/matching integration before satellite pairing; no training dataset or model has been generated by this stage. Technology and learning resources are logged in `study.md`.
